# InventoryLite

Мінімалістична офлайн‑програма для обліку товарів, касових операцій і базової аналітики. Працює на касовому методі, розраховує собівартість за середньозваженим методом і допомагає відслідковувати рух коштів без підключення до хмари.

## Огляд
- **Призначення**: невеликі торгові команди та ФОП, яким потрібен простий облік закупівель, продажів, залишків і касових транзакцій без складних ERP.
- **Платформа**: настільний застосунок на Tkinter; збірка через PyInstaller (onefile/onedir) для Windows. Дані зберігаються локально у SQLite.
- **Архітектура**: 
  - `app.py` — головний GUI з вкладками (довідники, документи, звіти, експорт).
  - `db.py` — шар доступу до SQLite, збереження довідників, документів, залишків і звітів.
  - `ui_components.py` — таблиці, діалоги та допоміжні елементи інтерфейсу.
  - `utils.py` — налаштування, шляхи даних, логування, резервні копії, робота з файловою системою.
- **Зберігання даних**: `%LOCALAPPDATA%\InventoryLite\` (або `~/.local/share/InventoryLite` на Linux/macOS при запуску з вихідних). Тут лежать `data.db`, `app.log`, резервні копії та експортовані CSV.

## Основні можливості
- **Касовий метод**: доходи/витрати фіксуються під час руху грошей; немає нарахувань.
- **Середньозважена собівартість**: окремо по кожному складу й товару, з підтримкою перерахунку залишків.
- **Мультивалюта**: довідник валют, точність до знаків після коми, курси з прив'язкою до дати документа та миттєвий перерахунок у базову валюту.
- **Довідники**: бренди, категорії, товари (пошук по SKU/назві), склади, канали продажу, контрагенти з типами, валюти.
- **Документи**: закупівлі, продажі, супутні витрати (доставка/митниця/комісії) з розподілом на закупівлі, статуси чернетка/проведено, блокування видалення проведених записів.
- **Каса**: оплати від клієнтів/постачальникам, інші доходи, змінні та постійні витрати; фільтри за датою, каналом, контрагентом.
- **Аналітика**: дашборд обороту, валового прибутку й маржі; продажі за каналами та категоріями; ABC/XYZ по товарах; рух коштів.
- **Залишки**: автоматичний реєстр із перерахунком, сервісна операція повного перерахунку, експорт у CSV.
- **Експорт і бекапи**: CSV для таблиць, повні резервні копії у ZIP, окремі копії БД; меню «Файл» → «Резервна копія…/Відновлення…».
- **Зручності**: блокування другої копії застосунку, загальні гарячі клавіші (копіювати/вставити/скасувати), настроювана тема (системна/світла/темна), вибір робочої теки та шрифтів редактора.

## Вимоги
- Python 3.13+ для збірки з вихідних.
- Залежності з `requirements.txt`: `pyinstaller`, `openpyxl`, `xlrd`.
- Windows для офіційної збірки onefile/onedir; запуск із вихідних можливий на Linux/macOS (Tkinter + SQLite).

## Збірка
### Швидкий варіант (Windows)
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
або у `cmd`:
```bat
build.bat
```

### Ручна команда PyInstaller
```powershell
py -3.13 -m PyInstaller --onedir --noconsole inventorylite/app.py
```
- Додаткові параметри: `--icon icons/app.ico` та `--name InventoryLite` (див. скрипти збірки).
- Іконка генерується автоматично з `icons/app_ico_base64.txt` у `icons/app.ico`, тому двійкових файлів у репозиторії немає.

## Запуск
- Після збірки відкрийте `dist\InventoryLite.exe` (one-file, без консолі) або `dist\app\InventoryLite.exe` (onedir).
- Запуск із вихідних для відлагодження:
  ```bash
  python -m inventorylite.app
  ```
  або
  ```bash
  python inventorylite/app.py
  ```
  Логи пишуться у `%LOCALAPPDATA%\InventoryLite\app.log`.

## Структура даних і резервні копії
- **Основні файли**: `data.db` (SQLite), `app.log` (логи), `settings.json` (налаштування), `backups/*.zip` (повні бекапи), `exports/*.csv` (експортовані таблиці).
- **Резервне копіювання**: меню «Файл» → «Резервна копія всіх даних» створює ZIP із БД, бекапами та експортами; «Резервна копія БД» — тільки `data.db`.
- **Відновлення**: меню «Файл» → «Відновлення з резервної копії» приймає ZIP, розпаковує в робочу теку даних і перезаписує файли.

## Поширені робочі сценарії
1. **Старт**: додайте валюту бази, склади та канали продажу, створіть бренди/категорії/товари.
2. **Закупівлі**: у вкладці «Закупівлі» створіть чернетку, додайте рядки товарів, зафіксуйте курс валюти (за потреби) і проведіть документ.
3. **Супутні витрати**: створіть документ «Супутні витрати», вкажіть суму доставки/митниці, розподіліть на обрані закупівлі, проведіть — витрати капіталізуються в собівартість.
4. **Продажі**: оформіть продаж із прив'язкою до каналу, валюти та курсу; після проведення залишки списуються за середньозваженою.
5. **Каса**: реєструйте оплати клієнтів/постачальникам або окремі доходи/витрати; фільтруйте за датою, каналом, контрагентом.
6. **Звіти/залишки**: перегляньте дашборд, ABC/XYZ, рух коштів; за потреби виконайте «повний перерахунок» залишків.

## Налаштування
- У меню «Файл» → «Налаштування» доступні параметри теми, робочої теки, профілю гарячих клавіш, базової валюти, шрифту редактора, рівня логування та URL документації/FAQ.
- Профіль гарячих клавіш можна скинути через «Скинути профіль гарячих клавіш».

## FAQ
- **Де зберігаються дані?** У `%LOCALAPPDATA%\InventoryLite\` (Windows) або `~/.local/share/InventoryLite` (Linux/macOS при запуску з вихідних): `data.db`, `app.log`, резервні копії, експорти.
- **Як запобігти запуску другої копії?** Застосунок створює файл блокування `app.lock` у теці даних; другу копію буде заблоковано автоматично.
- **Що робити, якщо валюта не має курсу на дату?** Під час створення документа програма запропонує ввести курс вручну; можна підставити останній доступний курс або задати новий.
- **Чи можна змінити базову валюту?** Так, у налаштуваннях укажіть код/назву/точність базової валюти; усі перерахунки та нові курси будуть використовувати ці значення.
- **Як відновити дані після переустановлення?** У меню «Файл» виберіть «Відновлення з резервної копії» та оберіть ZIP, створений раніше. Програма перезапише БД і файли даних.
- **Чому немає хмарної синхронізації?** InventoryLite задуманий як повністю офлайн‑рішення; обмін даними можна робити через CSV/ZIP‑бекапи вручну.
- **Які формати імпорту/експорту?** Експорт таблиць у CSV; продажі та закупівлі можна імпортувати/створювати з файлів Excel/CSV через відповідні діалоги імпорту.
- **Логи переповнюють диск?** Логування використовує ротацію (`app.log` до ~1 МБ, 3 резервні копії). За потреби змініть рівень логування в налаштуваннях підтримки.
- **Чи є темна тема?** Так: у налаштуваннях виберіть «Темна» або залиште «Системна» для успадкування теми ОС.
- **Запуск на Linux/macOS?** Можливо для відлагодження з вихідних (Tkinter + SQLite), але офіційні збірки тестуються на Windows.

## Підтримка
- Відкрити документацію/FAQ: меню «Файл» → «Документація/FAQ» (URL можна змінити в налаштуваннях).
- Журнали помилок: `%LOCALAPPDATA%\InventoryLite\app.log`. Додавайте їх при зверненні по допомогу.
