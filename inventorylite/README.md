# InventoryLite

Мінімалістична офлайн-програма для обліку товарів, касових операцій і базової аналітики.

## Що нового
- Касовий метод обліку: доходи/витрати фіксуються під час руху грошей, без нарахувань.
- Собівартість запасів розраховується за середньозваженим методом для кожного складу та товару.
- Підтримка мультивалюти з довідником валют, точністю до знаків після коми та таблицею курсів.
- Звіти: дашборд (оборот, валовий прибуток, маржа, вартість залишків), продажі за каналами/категоріями, ABC/XYZ-аналітика, рух коштів за фільтрами.
- Касові операції з типами (оплата від клієнта/постачальнику, інші доходи, змінні та постійні витрати) і фільтрами за датами, каналами та контрагентами.
- Розширені довідники: склади, канали продажу, валюти, контрагенти з типами.
- Документи закупівель і продажів з режимами чернетки/проведено, рядками, каналами збуту, курсом валюти та миттєвим перерахунком залишків.
- Автоматичний реєстр залишків із перерахунком і експортуванням, резервні копії всіх даних у ZIP і копії бази даних окремо.

## Як зібрати

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

або у cmd:

```bat
build.bat
```

Або вручну через PyInstaller (наприклад, у PowerShell):

```powershell
py -3.13 -m PyInstaller --onedir --noconsole app.py
```

Ця команда створює варіант `dist\app` у форматі `onedir`. За потреби можна додати параметри `--icon icons/app.ico` чи `--name InventoryLite` аналогічно до скриптів збірки.

Під час збірки іконка автоматично генерується з base64 (`icons/app_ico_base64.txt`) у `icons/app.ico`, тому двійкових файлів у репозиторії немає.

## Як запустити

Після збірки відкрийте `dist\InventoryLite.exe` (one-file, без консолі) або `dist\app\InventoryLite.exe` (onedir).

## Дані

База даних та журнали: `%LOCALAPPDATA%\InventoryLite\` (`data.db`, `app.log`, резервні копії, CSV-експорти).

## Основні можливості
- CRUD для брендів, категорій, товарів (з пошуком по SKU/назві), складів, каналів продажу, контрагентів і валют.
- Таблиця валютних курсів для перерахунку документів у базову валюту.
- Закупівлі та продажі з рядками, каналами збуту, статусами чернетка/проведено, мультивалютністю та блокуванням видалення проведених документів.
- Перевірка унікальності SKU та назв, дружні повідомлення про помилки.
- Касові операції з прив'язкою до документів або як самостійні рухи; фільтри за періодом/каналом/контрагентом.
- Автоматичний реєстр залишків із перерахунком на основі проведених документів та сервісною операцією повного перерахунку.
- Аналітика продажів (канали, категорії), ABC/XYZ по товарах, дашборд ключових показників і звіт руху коштів.
- Експорт таблиць у CSV, повні резервні копії даних у один ZIP та відновлення з нього, окремі бекапи БД через меню «Файл».
- Блокування другої копії додатку та загальні гарячі клавіші копіювання/вставки/скасування.
