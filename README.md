# PW

Цей репозиторій містить приклад настільної програми **InventoryLite** (папка `inventorylite`) для локального обліку товарів та касових операцій.

## InventoryLite

InventoryLite — це мінімалістичний офлайн-додаток для торговельного бізнесу з касовим методом обліку, рухом товарів і аналітичними звітами.

Основні можливості:
- Довідники брендів, категорій, товарів, складів, каналів продажу та контрагентів.
- Мультивалютні операції: довідник валют із точністю до десяткових знаків і таблиця курсів.
- Закупівлі й продажі з чернетками/проведенням, деталізованими рядками, каналами збуту та курсами валют.
- Автоматичний реєстр залишків за складом і товаром із перерахунком собівартості за середньозваженим методом.
- Касові операції (оплати постачальнику/від клієнта, інші доходи та витрати) з фільтрами за датами, каналами та контрагентами.
- Аналітика: дашборд із оборотом і валовим прибутком, продажі за каналами/категоріями, ABC/XYZ класифікація, звіт з руху коштів.
- Експорт таблиць у CSV та повні/часткові резервні копії з відновленням.

Докладні інструкції щодо збірки та використання див. у `inventorylite/README.md`.
